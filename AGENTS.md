# Agent instructions

All rules for AI agents working on this repository are in [CLAUDE.md](CLAUDE.md), and the design values
(colours, fonts, sizes) are in [DESIGN.md](DESIGN.md). Read both before starting any task and follow them,
whichever agent or tool you are.

Bu repoda çalışan tüm yapay zekâ ajanlarının kuralları [CLAUDE.md](CLAUDE.md) dosyasında, tasarım değerleri
[DESIGN.md](DESIGN.md) dosyasındadır. Hangi ajan olursan ol, işe başlamadan ikisini de oku ve uy.
